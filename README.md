# DMX
some simple DMX hardware with software


## Hardware

### DMXusb - simple USB-RS485 interface
* can be used to as PC-based DMX controller

### DMXpico - two Raspi Pi Pico based RS485 interfaces
* full control of timing, sending and receiving DMX frames
* stand-alone operation, communicates with PC via USB

### DMXctrl - simple stand-alone DMX controller 
* test device to generate DMX frames, very simple user interface
